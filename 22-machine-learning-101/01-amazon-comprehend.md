# Amazon Comprehend

- Amazon Comprehend is a natural language processing (NLP) service that uses machine learning to find insights and relationships in text.
- Input: Documents (text) in any language.
- Output: Insights and relationships in the text, such as:
  - Entity recognition (people, places, organizations, dates, quantities, etc.)
  - Key phrase extraction (important phrases in the text)
  - Language detection (detect the language of the text)
  - Personal Identifiable Information (PII) detection (detect sensitive information in the text, such as names, addresses, phone numbers, etc.)
  - Sentiment analysis (positive, negative, neutral, mixed)
- Can use pre-trained models or custom models (trained on your own data).
- Can perform real-time analysis for small workloads or asynchronous batch analysis for large workloads.
