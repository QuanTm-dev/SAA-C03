# Amazon SageMaker

- Amazon SageMaker is a fully managed service that provides the ability to build, train, and deploy machine learning models quickly.
- Core concepts:
  - SageMaker Studio: IDE for machine learning development lifecycle.
  - SageMaker Domain: A logical grouping of resources for SageMaker Studio. Think of it as a container for your machine learning projects.
  - Containers: Docker containers that contain the environment and dependencies needed to run your machine learning code.
  - Once a model is deployed, SageMaker creates an endpoint that your application can call to.
  - SageMaker has no cost, the resources it creates do.
