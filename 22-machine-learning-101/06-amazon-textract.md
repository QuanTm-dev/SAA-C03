# Amazon Textract

- Amazon Textract is a machine learning (ML) service that automatically extracts text, handwriting, and data from scanned documents.
- Input: document in JPEG, PNG, PDF, or TIFF format.
- Output: Extracted text, structured data (e.g., tables, forms).
- Lightweight document is processed synchronously, while larger documents are processed asynchronously.
- Amazon Textract also contain the metadata of extracted content, such as where the text is located on the page.
